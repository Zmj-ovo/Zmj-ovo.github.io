为什么选择 Hexo + GitHub Pages

Hexo 是一个快速、简洁且高效的静态博客框架。配合 GitHub Pages，可以零成本搭建一个属于自己的博客。

优势

  • 免费托管：GitHub Pages 提供免费的静态网站托管
  • Markdown 写作：使用 Markdown 编写文章，专注内容
  • 丰富的主题：社区提供了大量精美的主题
  • 一键部署：hexo deploy 即可发布到 GitHub Pages

hexo generate 生成静态文件
hexo deploy 部署到远程
hexo clean 清除缓存
