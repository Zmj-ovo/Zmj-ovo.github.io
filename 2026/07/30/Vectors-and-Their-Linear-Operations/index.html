Vectors and Their Linear Operations

Analytic Geometry

def : vector $\boldsymbol{a},\boldsymbol{b}\quad\boldsymbol{a}:=\overrightarrow{AB}\quad\boldsymbol{b}:=\overrightarrow{BC}\quad\boldsymbol{c}:=\overrightarrow{AC}$ $\boldsymbol{c}=\boldsymbol{a}+\boldsymbol{b}$ , if $|\boldsymbol{a}|=0$ then $\boldsymbol{a}=\vec{0}$ , $-\boldsymbol{a}$ have opposite direction with $\boldsymbol{a}$ and $|-\boldsymbol{a}|=|\boldsymbol{a}|$

rules for the addition of vectors $1^\circ$ associative $(\boldsymbol{a}+\boldsymbol{b})+\boldsymbol{c}=\boldsymbol{a}+(\boldsymbol{b}+\boldsymbol{c})\quad\forall\boldsymbol{a},\boldsymbol{b},\boldsymbol{c}$

$2^\circ$ commutative $\boldsymbol{a}+\boldsymbol{b}=\boldsymbol{b}+\boldsymbol{a}\quad\forall\boldsymbol{a},\boldsymbol{b}$

$3^\circ\quad\forall\boldsymbol{a}\quad\boldsymbol{a}+\vec{0}=\boldsymbol{a}$

$4^\circ\quad\forall\boldsymbol{a}\quad\boldsymbol{a}+(-\boldsymbol{a})=\vec{0}$

$1^\circ$ proof $\boldsymbol{a}:=\overrightarrow{OA}\quad\boldsymbol{b}:=\overrightarrow{AB}\quad\boldsymbol{c}:=\overrightarrow{BC}$ $\boldsymbol{a}+\boldsymbol{b}=\overrightarrow{OB}\quad(\boldsymbol{a}+\boldsymbol{b})+\boldsymbol{c}=\overrightarrow{OC}$ $\boldsymbol{b}+\boldsymbol{c}=\overrightarrow{AC}\quad\boldsymbol{a}+(\boldsymbol{b}+\boldsymbol{c})=\overrightarrow{OC}$ So $(\boldsymbol{a}+\boldsymbol{b})+\boldsymbol{c}=\boldsymbol{a}+(\boldsymbol{b}+\boldsymbol{c})$

$2^\circ$ proof Set $\boldsymbol{a}:=\overrightarrow{OA}\quad\boldsymbol{b}:=\overrightarrow{OB}\quad$ set a parallelogram $OABC$ $\boldsymbol{a}+\boldsymbol{b}=\boldsymbol{b}+\boldsymbol{a}=\overrightarrow{OC}$

$3^\circ$ proof $\boldsymbol{a}:=\overrightarrow{OA}\quad\vec{0}:=\overrightarrow{AA}$ $\boldsymbol{a}+\vec{0}=\overrightarrow{OA}=\boldsymbol{a}$

$4^\circ$ proof $\boldsymbol{a}:=\overrightarrow{OA}\quad-\boldsymbol{a}:=\overrightarrow{AO}$ $\boldsymbol{a}+(-\boldsymbol{a})=\overrightarrow{OO}=\vec{0}$

def: $\boldsymbol{a}-\boldsymbol{b}=\boldsymbol{a}+(-\boldsymbol{b})$

$\boldsymbol{a}:=\overrightarrow{OA}\quad\boldsymbol{b}:=\overrightarrow{OB}$ $\boldsymbol{a}-\boldsymbol{b}=\overrightarrow{OA}+\overrightarrow{BO}=\overrightarrow{BO}+\overrightarrow{OA}=\overrightarrow{BA}$ Since $ABO$ is a triangle So $|\overrightarrow{BA}|\leq|\overrightarrow{OA}|+|\overrightarrow{OB}|$ $\Leftrightarrow|\boldsymbol{a}-\boldsymbol{b}|\leq|\boldsymbol{a}|+|\boldsymbol{b}|$ Set $\boldsymbol{c}:=-\boldsymbol{b}$ $|\boldsymbol{a}+\boldsymbol{c}|\leq|\boldsymbol{a}|+|\boldsymbol{c}|\quad$ is the triangle inequality

def: $|\lambda\boldsymbol{a}|:=|\lambda|\cdot|\boldsymbol{a}|$ when $\lambda>0$ the direction of $\lambda\boldsymbol{a}$ is same with $\boldsymbol{a}$ when $\lambda<0$ the direction of $\lambda\boldsymbol{a}$ is opposite with $\boldsymbol{a}$

$\forall\boldsymbol{a}\quad0\boldsymbol{a}=0\cdot|\boldsymbol{a}|=0\quad$ so $0\boldsymbol{a}=\vec{0}$ $\forall\lambda\quad\lambda\vec{0}=|\lambda||\vec{0}|=0\quad$ so $\lambda\vec{0}=\vec{0}$ Set $\boldsymbol{a}\neq\vec{0}\quad\frac{\boldsymbol{a}}{|\boldsymbol{a}|}$ have same direction with $\boldsymbol{a}$ and $\left|\frac{\boldsymbol{a}}{|\boldsymbol{a}|}\right|=\frac{1}{|\boldsymbol{a}|}\cdot|\boldsymbol{a}|=1$ So $\boldsymbol{a}^\circ=\frac{\boldsymbol{a}}{|\boldsymbol{a}|}$ is the unit vector p\boldsymbol{a}rallel to $\boldsymbol{a}$

rules for scalar multiplication of vectors $1^\circ\quad1\boldsymbol{a}=\boldsymbol{a}\quad(-1)\boldsymbol{a}=-\boldsymbol{a}$ $2^\circ\quad\lambda(\mu\boldsymbol{a})=(\lambda\mu)\boldsymbol{a}$ $3^\circ\quad(\lambda+\mu)\boldsymbol{a}=\lambda\boldsymbol{a}+\mu\boldsymbol{a}$ $4^\circ\quad\lambda(\boldsymbol{a}+\boldsymbol{b})=\lambda\boldsymbol{a}+\lambda\boldsymbol{b}$

$1^\circ$ proof $1>0$ so $1\boldsymbol{a}$ and $\boldsymbol{a}$ have same direction $|1\boldsymbol{a}|=1\cdot|\boldsymbol{a}|=|\boldsymbol{a}|$ so $1\boldsymbol{a}=\boldsymbol{a}$ $-1<0$ so $(-1)\boldsymbol{a}$ and $-\boldsymbol{a}$ have same direction $|(-1)\boldsymbol{a}|=|-1||\boldsymbol{a}|=|\boldsymbol{a}|=|-\boldsymbol{a}|$ so $(-1)\boldsymbol{a}=-\boldsymbol{a}$

$2^\circ$ proof if $\lambda\cdot\mu>0$ then $(\lambda\mu)\boldsymbol{a}$ have same direction with $\boldsymbol{a}$ means $\lambda,\mu>0$ or $\lambda,\mu<0:\lambda(\mu\boldsymbol{a})$ have same direction with $\boldsymbol{a}$ if $\lambda\cdot\mu<0$ then $(\lambda\mu)\boldsymbol{a}$ have opposite direction with $\boldsymbol{a}$ means $\lambda>0,\mu<0$ or $\lambda<0,\mu>0:\lambda(\mu\boldsymbol{a})$ have opposite direction with $\boldsymbol{a}$

if $\lambda\cdot\mu=0$ then $\lambda=\vec{0}$ or $\mu=0$ or $\lambda=\mu=0$ $\lambda(\mu\boldsymbol{a})=(\lambda\mu)\boldsymbol{a}=\vec{0}$ So $\lambda(\mu\boldsymbol{a})$ and $(\lambda\mu)\boldsymbol{a}$ have same direction $|\lambda(\mu\boldsymbol{a})|=|\lambda|\cdot|\mu\boldsymbol{a}|=|\lambda|\cdot|\mu|\cdot|\boldsymbol{a}|=|\lambda\mu|\cdot|\boldsymbol{a}|=|(\lambda\mu)\cdot\boldsymbol{a}|$ So $\lambda(\mu\boldsymbol{a})=(\lambda\mu)\boldsymbol{a}$

$3^\circ$ proof $(\lambda+\mu)\boldsymbol{a}=\lambda\boldsymbol{a}+\mu\boldsymbol{a}$ if exist $\lambda=\vec{0}$ or $\mu=0$ or $\boldsymbol{a}=\vec{0}$ then equality holds

case1. $\lambda,\mu$ have same sign so $\lambda+\mu$ have same sign with $\lambda,\mu$ so $(\lambda+\mu)\boldsymbol{a}$ and $\lambda\boldsymbol{a}+\mu\boldsymbol{a}$ have same direction $|(\lambda+\mu)\boldsymbol{a}|=|\lambda+\mu||\boldsymbol{a}|=(|\lambda|+|\mu|)|\boldsymbol{a}|$ $=|\lambda||\boldsymbol{a}|+|\mu||\boldsymbol{a}|$ $=|\lambda\boldsymbol{a}|+|\mu\boldsymbol{a}|\quad$ since $\lambda\boldsymbol{a}$ and $\mu\boldsymbol{a}$ have same direction $=|\lambda\boldsymbol{a}+\mu\boldsymbol{a}|$ so $(\lambda+\mu)\boldsymbol{a}=\lambda\boldsymbol{a}+\mu\boldsymbol{a}$

case 2. $\lambda,\mu$ have different sign Set $\lambda>0\quad\mu<0$ (1) $\lambda+\mu=0$ $\mu=-\lambda$ $(\lambda+\mu)\boldsymbol{a}=\vec{0}=\lambda\boldsymbol{a}-\lambda\boldsymbol{a}$ So $(\lambda+\mu)\boldsymbol{a}=\lambda\boldsymbol{a}+\mu\boldsymbol{a}$

(2)$\lambda+\mu>0$ $\lambda+\mu>0\;,-\mu>0\quad$ use case1. $(\lambda+\mu-\mu)\boldsymbol{a}=(\lambda+\mu)\boldsymbol{a}-\mu\boldsymbol{a}$ $\lambda\boldsymbol{a}=(\lambda+\mu)\boldsymbol{a}-\mu\boldsymbol{a}$ $(\lambda+\mu)\boldsymbol{a}=\lambda\boldsymbol{a}+\mu\boldsymbol{a}$

(3)$\lambda+\mu<0\quad-\lambda<0$ $(\lambda+\mu-\lambda)\boldsymbol{a}=(\lambda+\mu)\boldsymbol{a}-\lambda\boldsymbol{a}$ $(\lambda+\mu)\boldsymbol{a}=\lambda\boldsymbol{a}+\mu\boldsymbol{a}$

$4^\circ$ proof $\lambda(\boldsymbol{a}+\boldsymbol{b})=\lambda\boldsymbol{a}+\lambda\boldsymbol{b}$ if exist $\lambda=\vec{0}$ or $\boldsymbol{a}=0$ or $\boldsymbol{b}=0$ then equality holds

when $\boldsymbol{a}\parallel\boldsymbol{b}$ then $\exists\mu\in\mathbb{R},\boldsymbol{a}=\mu\boldsymbol{b}$ $\lambda(\boldsymbol{a}+\boldsymbol{b})=\lambda(\mu\boldsymbol{b}+\boldsymbol{b})$ $=\lambda(1+\mu)\boldsymbol{b}$ using $3^\circ$ $=(\lambda+\lambda\mu)\boldsymbol{b}$ $=\lambda\boldsymbol{b}+\lambda\mu\boldsymbol{b}$ $=\lambda\boldsymbol{a}+\lambda\boldsymbol{b}$

when $\boldsymbol{a}\nparallel\boldsymbol{b}$ $\boldsymbol{a}:=\overrightarrow{OA}\quad\boldsymbol{b}:=\overrightarrow{AB}$ $\boldsymbol{a}+\boldsymbol{b}=\overrightarrow{OB}$ Set $\overrightarrow{OC}=\lambda\boldsymbol{a}\quad\overrightarrow{CD}=\lambda\boldsymbol{b}$ $\lambda\boldsymbol{a}+\lambda\boldsymbol{b}=\overrightarrow{OD}$ $\triangle OAB\sim\triangle OCD$ so $\lambda\overrightarrow{OB}=\overrightarrow{OD}=\lambda(\boldsymbol{a}+\boldsymbol{b})=\lambda\boldsymbol{a}+\lambda\boldsymbol{b}$

The set of vectors : Set $\boldsymbol{a}_1\cdots\boldsymbol{a}_n$ is a set of vector , $k_1\cdots k_n\in\mathbb{R}$ then $k_1\boldsymbol{a}_1+\cdots+k_n\boldsymbol{a}_n$ is a vector is the linear combination of $\boldsymbol{a}_1,\cdots,\boldsymbol{a}_n$ $k_1\cdots k_n$ are the coefficients of the linear combination

def: If a set of vector are represented by directed line segments emanating from the same initial point and all lie on a straight line (plane) then the vector set is collinear (coplanar)

If $\boldsymbol{a},\boldsymbol{b}$ collinear then $\boldsymbol{a}\parallel\boldsymbol{b}$ If $\boldsymbol{a}=\lambda\boldsymbol{b}\;,\boldsymbol{a}\parallel\boldsymbol{b}$

Prop.1.1 If $\boldsymbol{a},\boldsymbol{b}$ collinear, $\boldsymbol{a}\neq\vec{0}$ then $\exists$ unique $\lambda\in\mathbb{R}\quad\boldsymbol{b}=\lambda\boldsymbol{a}$

proof: Exist: if $\boldsymbol{a},\boldsymbol{b}$ have same direction $\frac{\boldsymbol{a}}{|\boldsymbol{a}|}=\frac{\boldsymbol{b}}{|\boldsymbol{b}|}$ $\boldsymbol{b}=\frac{|\boldsymbol{b}|}{|\boldsymbol{a}|}\boldsymbol{a}$ if $\boldsymbol{a},\boldsymbol{b}$ opposite direction , similar

unique: Assume $\boldsymbol{b}=\lambda\boldsymbol{a}=\mu\boldsymbol{a}$ then $(\lambda-\mu)\boldsymbol{a}=0$ since $\boldsymbol{a}\neq\vec{0}$ so $\lambda-\mu=0\Rightarrow\lambda=\mu$

Prop.1.2. $\boldsymbol{a},\boldsymbol{b}$ collinear iff $\exists$ nonzero $\lambda,\mu\in\mathbb{R},\lambda\boldsymbol{a}+\mu\boldsymbol{b}=\vec{0}$ proof: $\Rightarrow$ $\boldsymbol{a},\boldsymbol{b}$ collinear. if $\boldsymbol{a}=\boldsymbol{b}=\vec{0}$ then $1\cdot\boldsymbol{a}+1\cdot\boldsymbol{b}=\vec{0}$ if $\boldsymbol{a},\boldsymbol{b}$ nonzero, assume $\boldsymbol{a}\neq\vec{0}$ then $\exists\lambda\in\mathbb{R}\quad\boldsymbol{b}=\lambda\boldsymbol{a}\quad(\text{prop 1.1})$ so $\lambda\boldsymbol{a}-\boldsymbol{b}=\vec{0}$

$\Leftarrow$ $\exists$ nonzero $\lambda,\mu\quad\lambda\boldsymbol{a}+\mu\boldsymbol{b}=\vec{0}$ , assume $\lambda\neq0$ $\lambda\boldsymbol{a}=-\mu\boldsymbol{b}$ $\boldsymbol{a}=-\frac{\mu}{\lambda}\boldsymbol{b}$ So $\boldsymbol{a},\boldsymbol{b}$ collinear

Corollary 1.1 $\boldsymbol{a},\boldsymbol{b}$ noncollinear iff $\lambda\boldsymbol{a}+\mu\boldsymbol{b}=\vec{0}\Rightarrow\lambda=\mu=0$ proof: $\neg(\exists\text{ nonzero }\lambda,\mu\in\mathbb{R}\quad\lambda\boldsymbol{a}+\mu\boldsymbol{b}=\vec{0})$ $\Leftrightarrow\forall\text{ nonzero }\lambda,\mu\in\mathbb{R}\quad\lambda\boldsymbol{a}+\mu\boldsymbol{b}\neq\vec{0}$ $\Leftrightarrow\lambda\boldsymbol{a}+\mu\boldsymbol{b}=\vec{0}\Rightarrow\exists\lambda=\mu=0$

Prop.1.3 If $\boldsymbol{c}=\lambda\boldsymbol{a}+\mu\boldsymbol{b}$ then $\boldsymbol{a},\boldsymbol{b},\boldsymbol{c}$ coplanar proof: if $\boldsymbol{a}\parallel\boldsymbol{b}$ then $\boldsymbol{a},\boldsymbol{b},\boldsymbol{c}$ collinear so $\boldsymbol{a},\boldsymbol{b},\boldsymbol{c}$ coplanar. if $\boldsymbol{a}\nparallel\boldsymbol{b}$ then $\lambda\boldsymbol{a}:=\overrightarrow{OA}\quad\mu\boldsymbol{b}:=\overrightarrow{AB}$ $\boldsymbol{c}=\lambda\boldsymbol{a}+\mu\boldsymbol{b}=\overrightarrow{OB}$ so $\boldsymbol{a},\boldsymbol{b},\boldsymbol{c}$ on the plane $OAB$ so $\boldsymbol{a},\boldsymbol{b},\boldsymbol{c}$ coplanar

Prop.1.4 If $\boldsymbol{a},\boldsymbol{b},\boldsymbol{c}$ coplanar and $\boldsymbol{a},\boldsymbol{b}$ noncollinear then $\exists$ unique $\lambda,\mu\in\mathbb{R}$ $\boldsymbol{c}=\lambda\boldsymbol{a}+\mu\boldsymbol{b}$

proof: $\exists$ Exist: Set $\boldsymbol{a}:=\overrightarrow{OA}\quad\boldsymbol{b}:=\overrightarrow{OB}\quad\boldsymbol{c}:=\overrightarrow{OC}$ Set $CD\parallel OB\quad OA\cap CD=D$ , since $CD\parallel OB$ so $\exists\lambda\in\mathbb{R}$ Since $OA\parallel OD\quad CD\parallel OB$ so $\exists\lambda,\mu\in\mathbb{R}$ $\overrightarrow{OD}=\lambda\boldsymbol{a}\quad\overrightarrow{DC}=\mu\boldsymbol{b}$ $\lambda\boldsymbol{a}+\mu\boldsymbol{b}=\boldsymbol{c}$

Unique: Assume $\boldsymbol{c}=\lambda_1\boldsymbol{a}+\mu_1\boldsymbol{b}=\lambda_2\boldsymbol{a}+\mu_2\boldsymbol{b}$ then $(\lambda_1-\lambda_2)\boldsymbol{a}+(\mu_1-\mu_2)\boldsymbol{b}=0$ Since $\boldsymbol{a},\boldsymbol{b}$ noncollinear then $\lambda_1-\lambda_2=0\quad\mu_1-\mu_2=0\quad(\text{Cor 1.1})$ $\lambda_1=\lambda_2\;;\mu_1=\mu_2$

Prop.1.5 $\boldsymbol{a},\boldsymbol{b},\boldsymbol{c}$ coplanar iff $\exists$ nonzero $k_1,k_2,k_3\in\mathbb{R},\;k_1\boldsymbol{a}+k_2\boldsymbol{b}+k_3\boldsymbol{c}=\vec{0}$

$\Rightarrow\boldsymbol{a},\boldsymbol{b},\boldsymbol{c}$ coplanar if $\boldsymbol{a}\nparallel\boldsymbol{b}$ then $\exists\lambda,\mu\in\mathbb{R}\;\boldsymbol{c}=\lambda\boldsymbol{a}+\mu\boldsymbol{b}$ then $\lambda\boldsymbol{a}+\mu\boldsymbol{b}-\boldsymbol{c}=\vec{0}\quad$ note $-1\neq0$ if $\boldsymbol{a}\parallel\boldsymbol{b}$ then $\exists$ nonzero $\lambda,\mu\quad\lambda\boldsymbol{a}+\mu\boldsymbol{b}=\vec{0}$ then $\lambda\boldsymbol{a}+\mu\boldsymbol{b}+0\cdot\boldsymbol{c}=\vec{0}\quad\lambda\text{ or }\mu\neq0$

$\Leftarrow\exists$ nonzero $k_1,k_2,k_3\in\mathbb{R}\quad k_1\boldsymbol{a}+k_2\boldsymbol{b}+k_3\boldsymbol{c}=\vec{0}$ Assume $k_1\neq0$ then $\boldsymbol{a}=-\frac{k_2}{k_1}\boldsymbol{b}-\frac{k_3}{k_1}\boldsymbol{c}$ so $\boldsymbol{a},\boldsymbol{b},\boldsymbol{c}$ coplanar

Cor 1.2 $\boldsymbol{a},\boldsymbol{b},\boldsymbol{c}$ noncoplanar iff $k_1\boldsymbol{a}+k_2\boldsymbol{b}+k_3\boldsymbol{c}=\vec{0}\Rightarrow k_1=k_2=k_3=0$

proof: $\neg(\exists\text{ nonzero }k_1,k_2,k_3\in\mathbb{R},k_1\boldsymbol{a}+k_2\boldsymbol{b}+k_3\boldsymbol{c}=\vec{0})$ $\Leftrightarrow\forall\text{ nonzero }k_1,k_2,k_3\in\mathbb{R},\;k_1\boldsymbol{a}+k_2\boldsymbol{b}+k_3\boldsymbol{c}\neq\vec{0}$ $\Leftrightarrow k_1\boldsymbol{a}+k_2\boldsymbol{b}+k_3\boldsymbol{c}=\vec{0}\Rightarrow\exists k_1,k_2,k_3=0$

Ex1. Prove point $M$ on the line segment $AB$ iff $\exists$ nonnegative $\lambda,\mu\in\mathbb{R}$ $\overrightarrow{OM}=\lambda\overrightarrow{OA}+\mu\overrightarrow{OB}$ and $\lambda+\mu=1\quad$ point $O$ is arbitrary

proof: $\Rightarrow M$ on $AB$ , $\overrightarrow{AM}\parallel\overrightarrow{AB}$ and $0\leq|\overrightarrow{AM}|\leq|\overrightarrow{AB}|$ So $\overrightarrow{AM}=k\overrightarrow{AB}\quad0\leq k\leq1$ So $\overrightarrow{OM}-\overrightarrow{OA}=k(\overrightarrow{OB}-\overrightarrow{OA})$ $\overrightarrow{OM}=(1-k)\overrightarrow{OA}+k\overrightarrow{OB}$ $\lambda=1-k\quad\mu=k\quad\lambda+\mu=1\quad\lambda,\mu\geq0$

$\Leftarrow\overrightarrow{AM}=\overrightarrow{OM}-\overrightarrow{OA}=(\lambda-1)\overrightarrow{OA}+\mu\overrightarrow{OB}=\mu\overrightarrow{OB}-\mu\overrightarrow{OA}=\mu(\overrightarrow{OB}-\overrightarrow{OA})$ $=\mu\overrightarrow{AB}\quad0\leq\mu\leq1$ so $M$ on the line segment $AB$

Ex2 Prove $A,B,C$ collinear iff $\exists$ nonzero $\lambda,\mu,\nu\in\mathbb{R}$ $\lambda\overrightarrow{OA}+\mu\overrightarrow{OB}+\nu\overrightarrow{OC}=\vec{0}$ and $\lambda+\mu+\nu=0\quad O$ is arbitrary point

proof $\Rightarrow$ $A,B,C$ collinear $\Rightarrow\overrightarrow{AB}\parallel\overrightarrow{AC}$ So $\exists$ nonzero $k,\ell\in\mathbb{R}$ $k\overrightarrow{AB}+\ell\overrightarrow{AC}=\vec{0}$ $k(\overrightarrow{OB}-\overrightarrow{OA})+\ell(\overrightarrow{OC}-\overrightarrow{OA})=\vec{0}$ $(-k-\ell)\overrightarrow{OA}+k\overrightarrow{OB}+\ell\overrightarrow{OC}=\vec{0}$ $\lambda=-k-\ell\quad\mu=k\quad\nu=\ell\quad\lambda+\mu+\nu=0$

$\Leftarrow$ $\lambda=-\mu-\nu$ $(-\mu-\nu)\overrightarrow{OA}+\mu\overrightarrow{OB}+\nu\overrightarrow{OC}=\vec{0}$ $\mu(\overrightarrow{OB}-\overrightarrow{OA})+\nu(\overrightarrow{OC}-\overrightarrow{OA})=\vec{0}$ $\mu\overrightarrow{AB}+\nu\overrightarrow{AC}=\vec{0}$ if $\mu=\nu=0$ then $\lambda=\mu=\nu=0$ but $\lambda,\mu,\nu$ is nonzero so $\mu,\nu$ is nonzero so $\overrightarrow{AB}\parallel\overrightarrow{AC}$ so $A,B,C$ collinear

Qiu, W. S. Analytic Geometry. Peking University Press.
